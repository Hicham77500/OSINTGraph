## 2. Architecture actuelle

```
Electron → React SPA → Zustand (graphStore) → Cytoscape
                    ↘ REST / IPC → FastAPI → SQLite (graphs blob)
                                      ↘ transforms/ (plugins OSINT)
```

- **Frontend** : vue unique (pas de routing), graphe comme écran principal.
- **Backend** : 3 routers (`graph`, `transforms`, `workspaces`), transforms synchrones dans la requête HTTP.
- **Modèle** : 6 types de nœuds, 4 types d'arêtes ; pas de dossiers, carnets, provenance structurée.

**Documenté mais absent** : Neo4j, Agent-OS (`agents/`), `useUIStore`, streaming Socket.IO côté frontend.

## 7. Organisation métier actuelle

```
Workspace (ex: "default")
  └── Graph JSON { nodes[], edges[] }
        node: { id, type, label, properties, metadata? }
        edge: { id, source, target, type, label? }
```

Pas de : dossiers, carnets, provenance obligatoire, statuts de confiance, audit trail.

---

## 8. Organisation métier cible

```
Dossier → Carnet → Entité → Source → Observation → Evidence → Relation → Hypothesis → Analyse IA
```

Statuts de confiance : `CONFIRMED | LIKELY | POSSIBLE | UNVERIFIED | CONTRADICTED`.

Migration : dual-write incrémental ; `workspace_id` alias de `dossier_id` pendant la transition.
